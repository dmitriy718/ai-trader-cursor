# .gitignore Quick Reference

## 🚫 What Gets Ignored (Protected)

### Secrets & Credentials
- `.env` and all `.env.*` files (except `.env.example`)
- Any file with `*api*key*`, `*secret*`, `*token*` in name
- Configuration files with secrets (`config/secrets.yaml`, etc.)

### Database Files
- `*.db`, `*.sqlite`, `*.db-shm`, `*.db-wal`
- `data/` directory
- Database backups (`*.backup`, `*.bak`)

### Logs
- `logs/` directory
- `*.log` files
- `stress_test.log`

### Models
- `models/*.tflite`, `models/*.h5`, `models/*.pb`
- Trained model directories

### Python Artifacts
- `__pycache__/`, `*.pyc`, `*.pyo`
- Virtual environments (`venv/`, `.venv/`, `env/`)
- Distribution files (`dist/`, `build/`, `*.egg-info/`)

### IDE Files
- `.vscode/`, `.idea/`, `*.swp`, `*.swo`

### OS Files
- `.DS_Store` (macOS)
- `Thumbs.db` (Windows)
- `*~` (Linux backups)

## ✅ What Gets Committed (Safe)

- `.env.example` (template file)
- `config/config.yaml` (public config)
- Source code (`.py` files)
- Documentation (`.md` files)
- `requirements.txt`
- `Dockerfile`, `docker-compose.yml`
- Test files

## 🔍 Quick Checks

```bash
# Check what would be ignored
git status --ignored

# Verify .env is ignored
git check-ignore .env

# List all ignored files
git ls-files --others --ignored --exclude-standard
```

## ⚠️ Common Mistakes to Avoid

1. ❌ Don't commit `.env` files
2. ❌ Don't hardcode API keys in source code
3. ❌ Don't commit database files
4. ❌ Don't commit log files
5. ❌ Don't commit model files (unless open source)
6. ✅ Do use `.env.example` as template
7. ✅ Do use environment variables for all secrets
8. ✅ Do review `git status` before committing
